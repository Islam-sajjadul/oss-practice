# Chapter 4 Git Practice

## What I learned

- Git tracks changes in a repository.
- `git add` stages changes.
- `git commit` saves changes to local history.
- `git push` sends local commits to GitHub.
- `git pull` brings changes from GitHub to the local repository.

## Git workflow

1. Check the status with `git status`.
2. Stage changes with `git add`.
3. Commit changes with `git commit`.
4. Push changes with `git push`.
